# Лаба 3: View Page - CRUD JavaScript App

## Опис
Проста сторінка перегляду з можливостями сортування, пошуку та підрахунку статистики.

## Функціонал
- ✅ Сортування фільмів (за назвою, роком, рейтингом, тривалістю)
- ✅ Пошук за назвою фільму
- ✅ Підрахунок загальної тривалості всіх фільмів
- ✅ Підрахунок середнього рейтингу
- ✅ Підрахунок кількості фільмів

## Використані методи масивів
- `filter()` - для пошуку
- `sort()` - для сортування
- `reduce()` - для підрахунку статистики
- `map()` - для рендерингу
