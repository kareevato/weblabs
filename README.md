Film Shop - це сучасний веб-додаток для продажу фільмів онлайн, який включає:

- 🎯 **Каталог фільмів** з пошуком та фільтрацією
- 👤 **Система автентифікації** з безпечним зберіганням паролів
- 🛒 **Кошик покупок** з індивідуальним зберіганням для кожного користувача
- 💳 **Оформлення замовлень** з повною валідацією даних
- 🔒 **Захищені маршрути** для авторизованих користувачів
- 📱 **Адаптивний дизайн** для всіх пристроїв

**Основні реалізації:**

**Змінені файли:**
- `backend/src/server.js` - endpoints для реєстрації та входу

- `src/pages/Login/login.js` - форма входу
