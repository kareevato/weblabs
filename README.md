# 🎬 Film Lab - CRUD Application

Веб-додаток для управління каталогом фільмів з повним функціоналом CRUD (Create, Read, Update, Delete) операцій через REST API.

## 📋 Опис

Film Lab - це повнофункціональний веб-додаток для управління каталогом фільмів, який включає:
- Перегляд списку фільмів з сортуванням та пошуком
- Створення нових фільмів
- Редагування існуючих фільмів
- Видалення фільмів
- Статистику (загальна тривалість, середній рейтинг, кількість фільмів, загальні перегляди)

## Технології

- **Frontend**: HTML, CSS, JavaScript (Vanilla JS)
- **Backend**: Node.js, Express.js
- **База даних**: JSON файл (db.json)

## Структура проекту

```
film_lab/
├── backend/
│   ├── server.js          # Express сервер з REST API
│   ├── db.json           # База даних (JSON)
│   ├── package.json      # Залежності проекту
│   └── node_modules/     # Встановлені пакети
├── frontend/
│   ├── index.html        # Головна сторінка
│   ├── create.html       # Створення нового фільму
│   ├── edit.html         # Редагування фільму
│   ├── app.js           # JavaScript логіка
│   └── style.css        # Стилізація
└── README.md            # Документація
```
