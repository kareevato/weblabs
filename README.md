# 🌐 Weblab2 - Advanced Landing Page

## 📋 Опис завдання

Покращення лендінг-сторінки відповідно до заданого дизайну (такого ж, як у попередній роботі) шляхом додавання повної адаптивності та анімацій.

## 📦 Реалізовані функції

### ✅ Адаптивність
- **Mobile (320px - 480px)**: Повна адаптація для мобільних пристроїв
- **Tablet (481px - 768px)**: Оптимізація для планшетів
- **Desktop (769px - 1024px)**: Стандартні десктопи
- **Large Desktop (1025px - 2560px)**: Великі екрани
- **4K (2561px+)**: Центрування контенту для 4K екранів

### ✅ Гамбургер-меню
- Адаптивне меню, яке згортається на екранах менше 768px
- Плавна анімація відкриття/закриття
- Закриття при кліку на посилання або поза меню
- JavaScript для інтерактивності

### ✅ Анімації (5+ реалізовано)
1. **Fade In Up** - поява елементів при завантаженні сторінки
2. **Pulse** - пульсація логотипу
3. **Slide In Right** - поява кнопок з правого боку
4. **Bounce** - підстрибування кнопок при hover
5. **Rotate** - обертання іконок при hover
6. **Hover transitions** - плавні переходи для всіх інтерактивних елементів

## 🎨 Особливості реалізації

- **CSS Variables** для легкого управління кольорами та розмірами
- **Модульна архітектура** для легкої підтримки
- **Smooth scroll** для навігації по сторінці
- **Intersection Observer** для анімацій при прокрутці
- **Оптимізовані медіа-запити** для всіх breakpoints
- **Accessibility** - семантична HTML розмітка та ARIA labels
