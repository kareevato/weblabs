# Web Lab 8 - Item page with interactivity

## Опис
Повний проект з Home, Catalog та Item сторінками. Включає всі функції з lab 6 та lab 7 плюс:
- Item page з детальною інформацією
- Пошук на Catalog сторінці
- Фільтри по жанру, року, рейтингу
- View more функціональність на Home сторінці
- View more кнопки ведуть на Item page

- ## Структура
- `src/components/` - React компоненти
- `src/pages/` - сторінки (Home, Catalog, Item)
- `src/contexts/` - FilmsContext для управління станом
