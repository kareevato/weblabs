# Лаба 4: Create/Edit Pages - CRUD JavaScript App

## Опис
Додавання сторінок створення та редагування фільмів з валідацією форм.

## Функціонал
- ✅ Створення нового фільму (create.html)
- ✅ Редагування існуючого фільму (edit.html)
- ✅ Валідація форм через HTML атрибути
- ✅ JavaScript валідація з модальними вікнами
- ✅ Збереження даних в localStorage

## Валідація
- Назва: мінімум 2 символи, максимум 100
- Жанр: мінімум 2 символи, максимум 50
- Тривалість: від 1 до 600 хвилин
- Рік: від 1888 до 2025
- Рейтинг: від 0 до 10
